  GeoPandas/Shapely, PostGIS, and documented public-source provenance across
  5,290 Census block groups.
- Implemented a versioned FastAPI API with typed WGS84 GeoJSON, server-side
  spatial/score filters, safe errors, and regression tests.
- Delivered an accessible React/TypeScript MapLibre explorer with score
  styling, transit/service toggles, filters, and clicked block-group details.
- Added CRS-aware ETL validation, quarantine, transactional loading, lineage,
  and optional ArcGIS Pro/Online runbooks without coupling the core to Esri
  licensing.

  through local PostGIS reproduction and automated regression coverage.
